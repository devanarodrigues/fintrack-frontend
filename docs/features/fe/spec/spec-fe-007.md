# FE-007 - Gerar Relatórios

## Objetivo

Permitir que o usuário gere relatórios financeiros em PDF a partir dos dados cadastrados no sistema.

## Escopo

### Incluído
- Relatório mensal
- Relatório anual
- Relatório por período personalizado
- Visualização prévia dos dados
- Download em PDF

### Não Incluído
- Edição de dados
- Exportação Excel
- Compartilhamento por e-mail

## Requisitos Funcionais

### RF-001
Gerar relatório mensal.

### RF-002
Gerar relatório anual.

### RF-003
Gerar relatório por período personalizado.

### RF-004
Exibir resumo financeiro.

### RF-005
Exibir gastos por categoria.

### RF-006
Exibir gastos por cartão.

### RF-007
Permitir download do PDF.
