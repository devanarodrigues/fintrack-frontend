# FE-002 - Gerenciar Gastos

## Objetivo

Permitir que o usuário gerencie seus gastos através de lançamento manual e upload de faturas PDF.

## Escopo

### Incluído
- Adicionar gasto manual
- Upload de fatura PDF
- Listar gastos
- Editar gasto
- Excluir gasto

### Não Incluído
- OCR
- Processamento da fatura
- Relatórios

## Requisitos Funcionais

### RF-001
Adicionar gasto manual.

### RF-002
Realizar upload de faturas PDF.

### RF-003
Listar gastos existentes.

### RF-004
Editar gastos.

### RF-005
Excluir gastos.

### RF-006
Pesquisar gastos.
