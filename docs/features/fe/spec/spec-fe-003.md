# FE-003 - Upload de Faturas

## Objetivo

Permitir que o usuário envie faturas em PDF para processamento automático.

## Escopo

### Incluído
- Seleção de arquivo PDF
- Validação do arquivo
- Envio para API
- Acompanhamento de status
- Exibição de erros

### Não Incluído
- OCR
- Extração de transações
- Revisão dos dados extraídos

## Requisitos Funcionais

### RF-001
Selecionar arquivo PDF.

### RF-002
Validar formato do arquivo.

### RF-003
Enviar arquivo para processamento.

### RF-004
Exibir status do processamento.

### RF-005
Exibir mensagens de erro.
