# FE-001 - Home Dashboard

## Objetivo

Fornecer ao usuário uma visão consolidada de sua situação financeira atual e futura, através de indicadores financeiros calculados a partir dos gastos cadastrados no sistema.

## Escopo

### Incluído
- Exibição dos principais indicadores financeiros
- Exibição da previsão do próximo mês
- Menu principal de navegação
- Layout responsivo

### Não Incluído
- Cadastro de gastos
- Upload de faturas
- Relatórios
- Autenticação

## Requisitos Funcionais

### RF-001 - Exibir Total Gasto
### RF-002 - Exibir Cartão com Maior Participação
### RF-003 - Exibir Maior Gasto
### RF-004 - Exibir Total de Parcelas Futuras
### RF-005 - Exibir Total de Despesas Fixas
### RF-006 - Exibir Previsão de Gastos do Próximo Mês
### RF-007 - Exibir Menu de Navegação
### RF-008 - Navegar para Outras Capacidades
